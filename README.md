# Simple Calculator (C++)

A simple command-line calculator built using C++. This is one of my first C++ practice projects, created to strengthen my understanding of basic programming concepts.

## Features

- Performs basic arithmetic operations:
  - Addition (`+`)
  - Subtraction (`-`)
  - Multiplication (`*`)
  - Division (`/`)
- Accepts decimal numbers using the `double` data type.
- Uses a separate function to perform calculations.
- Uses a `switch` statement to select the appropriate arithmetic operation.

## Concepts Practiced

While building this project, I practiced:

- **Functions:** Creating and calling a function that accepts parameters and returns a value.
- **Switch Statements:** Using `switch-case` to handle different arithmetic operators.
- **Data Types:** Working with `double` for decimal numbers and `char` for operators.
- **User Input and Output:** Using `cin` and `cout` to interact with the user.
- **Return Statements:** Returning calculation results from a function.

## How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/kedirbeka478-stack/Simple-Calculator
   ```

2. Navigate to the project directory:

   ```bash
   cd Simple-Calculator
   ```

3. Compile the C++ source file:

   ```bash
   g++ calculator.cpp -o calculator
   ```

4. Run the program:

   ```bash
   ./calculator
   ```

   On Windows, run:

   ```bash
   calculator.exe
   ```
